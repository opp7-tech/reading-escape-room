للتجربة على الكمبيوتر:
١. افتح index.html في Chrome.
٢. أدخل اسم الطالبة.
٣. افتح الأبواب الخمسة؛ كل باب لعبة مختلفة (٥ أسئلة/مهام).
٤. لا يمكن تجاوز سؤال أو باب قبل الحل الصحيح.
٥. بعد إنهاء ٢٥ مهمة تُتاح شهادة PNG يمكن تنزيلها أو حفظ صورتها.

لشواهد الطالبات: افتح worksheets.html واطبع الصفحات الخمس.

للنشر: ارفع المجلد كاملًا إلى خدمة استضافة مواقع ثابتة مثل GitHub Pages أو Cloudflare Pages.

كافة الملفات الأصلية القابلة للتعديل داخل مجلدات css و js و assets.
للتفاصيل الدقيقة اقرأ README.md.
