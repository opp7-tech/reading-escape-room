# غرفة الهروب من التعثّر القرائي 🏰

**موقع تعليمي تفاعلي كامل** لمادة لغتي – الصف الثاني الابتدائي.

- المدرسة: الابتدائية الثانية
- إعداد المعلمة: عزيزة العنزي
- مديرة المدرسة: ريم العنزي

## المحتويات

```
index.html                صفحة اللعبة الرئيسية
worksheets.html           خمس صفحات شواهد قابلة للطباعة
css/style.css             شكل الموقع ومقاسات الجوال
css/worksheets.css        تنسيق صفحات الشواهد والطباعة
js/content.js             المهارات والأسئلة والإجابات (يمكن تعديلها)
js/app.js                 برمجة المراحل الخمس وشهادة الإنجاز
assets/castle.svg         رسم القلعة
assets/icon.svg           أيقونة الموقع
manifest.webmanifest      إعدادات تثبيت الموقع على الشاشة الرئيسية
sw.js                     تخزين ملفات الموقع للعمل دون إنترنت بعد الزيارة الأولى عبر HTTPS
```

## تجربة اللعبة قبل النشر

1. فك الضغط عن ملف المشروع ZIP.
2. افتح `index.html` بمتصفح Chrome على الكمبيوتر. ويمكن فتحه محليًا على الجوال إذا كان المتصفح يسمح بفتح ملفات HTML المحلية.
3. أدخل اسمًا تجريبيًا، ثم حل البوابات الخمس بالترتيب.
4. عند إنهاء جميع المهام (25 مهمة) تظهر صفحة الشهادة؛ اضغط «حفظ الشهادة كصورة» لتنزيل PNG، أو «عرض صورة الشهادة» للاحتفاظ بها في معرض صور الجوال.
5. يمكن فتح `worksheets.html` وطباعة صفحات الشواهد الخمس.

**ملاحظة:** بعض هواتف الجوال لا تتعامل بسهولة مع ملف HTML محلي. الأفضل فتح النسخة على استضافة ويب برابط HTTPS.

## نشر الموقع مجانًا كرابط مباشر (بدون قاعدة بيانات)

طريقة GitHub Pages (يمكن تنفيذها من الكمبيوتر):

1. أنشئ مستودع GitHub جديدًا عامًا، مثل `reading-escape`.
2. ارفع **محتويات المجلد** إلى جذر المستودع، بحيث يظهر `index.html` مباشرة في الصفحة الرئيسية للمستودع.
3. افتح `Settings → Pages`.
4. في `Build and deployment` اختر `Deploy from a branch` ثم الفرع `main` والمجلد `/ (root)`، واضغط حفظ.
5. افتح رابط Pages الذي تعرضه GitHub بعد اكتمال النشر. هذا هو الرابط الذي يفتح منه الطالبات الموقع.
6. أنشئ رمز QR من الرابط النهائي وأدرجه في إعلان المشروع أو أوراق الشواهد.

يمكن أيضًا استخدام Cloudflare Pages أو أي استضافة صفحات ثابتة؛ لا تتطلب الملفات تشغيل خادم برمجي أو قاعدة بيانات.

## قواعد اللعب

- خمسة أبواب، داخل كل باب **خمس مهام**، وكل باب لعبة مختلفة: صيد الصوت، تركيب الحروف، ترتيب الكلمات، البحث عن الدليل، إكمال الإملاء.
- لا يوجد زر لتجاوز المهمة؛ يجب حل السؤال حلًا صحيحًا حتى يظهر زر التالي.
- الأبواب التالية مغلقة حتى تُحل جميع أسئلة الباب الحالي.
- لا يتم توليد الشهادة إلا بعد إكمال **جميع المهام الـ25**.
- الاسم يظهر في الشهادة وفي اسم ملف PNG.
- تلميحات الخطأ لا تكشف الإجابة الصحيحة.

## خصوصية الطالبات والنتائج

- **لا توجد قاعدة بيانات سحابية، ولا حسابات، ولا لوحة تحكم، ولا إرسال لأسماء الطالبات أو الدرجات إلى أي خادم.**
- تقدم اللعب محفوظ مؤقتًا داخل **التبويب الحالي** باستخدام `sessionStorage` لحماية التقدم عند التحديث؛ قد يُمسح عند إغلاق التبويب أو مسح بيانات المتصفح.
- الشهادة تُنشأ داخل جهاز الطالبة ويمكن حفظها أو طباعتها؛ المعلمة لا تستقبلها تلقائيًا.
- هذه شهادة **إتمام اللعبة** وليست شهادة تحقق رسمية ضد التلاعب؛ في المواقع دون خادم لا يمكن منع التلاعب التقني المتعمد بصورة مطلقة.
- تقويم القراءة الجهرية والطلاقة يحتاج ملاحظة المعلمة؛ اللعبة تقيس إنجاز المهام الإلكترونية فقط ولا تثبت بمفردها ارتفاع نواتج التعلم دون قياس قبلي/بعدي.

## تعديل الأسئلة

افتح `js/content.js` في أي محرر نصوص. يضم محتوى كل باب والأسئلة والإجابات. يُفضّل مراجعة المحتوى لغويًا وتربويًا قبل تعميمه؛ عند تغيير عدد الأسئلة يجب تعديل منطق عدد المهام في `js/app.js` بما يلائم العدد الجديد (التصميم الحالي 5 لكل باب).

## تحديث الموقع بعد النشر

استبدل الملفات المعدلة على الاستضافة. إذا لم يظهر التحديث بسبب التخزين المؤقت، عدّل قيمة `CACHE` في ملف `sw.js` برقم إصدار جديد وأعد النشر، ثم حدّث الصفحة.

## ملفات مستقلة

يتضمن التسليم أيضًا ملفًا باسم `نسخة_واحدة_للتجربة.html` يمكن فتحه وحده دون بقية الملفات (لا يشمل رابط صفحة الشواهد). **النسخة المعتمدة للنشر هي المجلد الكامل**.
